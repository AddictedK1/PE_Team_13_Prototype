Title: Software Development Engineer (SDE I)

Responsibilities:
- Design, develop, test, and deploy reliable software services and applications.
- Collaborate with cross-functional teams to solve technical challenges.
- Write clean, maintainable, and well-tested code following best engineering practices.
- Participate in code reviews and contribute to system architecture discussions.

Requirements:
- Strong programming fundamentals in at least one modern language (e.g., Python, Java, C++, Go, TypeScript).
- Solid grasp of data structures, algorithms, and object-oriented design.
- Hands-on experience building software projects, internships, or practical applications.
- Demonstrated problem-solving ability and debugging skills.
- Basic understanding of databases, version control (Git), and software testing.
- Effective written and verbal communication and teamwork skills evidenced by project collaboration.
